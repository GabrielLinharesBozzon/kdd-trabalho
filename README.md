# Trabalho prático — ordenação de palavras

Programa em Python que lê `texto.txt`, compara Bubble Sort, Selection Sort e `sort()` nativo, mede os tempos e grava o resultado em `palavras_ordenadas.txt`.

## Como executar

1. Coloque o texto que deseja ordenar em `texto.txt`.
2. Execute `python kdd.py` nesta pasta.
3. Consulte os tempos exibidos e o arquivo `palavras_ordenadas.txt` criado.

O programa preserva a pontuação e a grafia das palavras, comparando-as sem diferenciar maiúsculas e minúsculas.
